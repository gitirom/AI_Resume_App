# AI Resume Analyzer

A deep learning-powered application for analyzing resumes, extracting skills, classifying sections, scoring quality, and matching jobs.

## Features
- Resume parsing and extraction
- Skill extraction and matching
- Section classification
- Quality scoring
- SWOT analysis
- Job matching

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
